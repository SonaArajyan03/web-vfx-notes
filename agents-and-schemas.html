Notes on web game VFX
Particle effects, frame budgets, and authoring workflow for HTML5 games.

Give the agent a schema, not an API

“Make the explosion punchier” has no executable meaning. That single fact explains most of why agents are unhelpful at VFX.

Hand an agent a rendering API and ask for a better effect and you get confident, plausible, wrong code: parameters invented, magic numbers that do nothing, a system rebuilt from scratch because reading the existing one was harder than replacing it. Not because the model is weak, but because there is no feedback signal. It cannot see the result, and nothing it writes fails loudly when the look is off.

What changes the outcome

Give it data with a schema instead of code with an API. Three things become true at once:

  • The space of valid edits is enumerable. A schema says the fields, their types, their ranges. The agent is picking values inside a known space rather than inventing structure, which is the thing it is worst at.
  • There is a checker. A validator that exits non-zero converts “does this look right” into a command. The agent can iterate against it without a human in the loop for every attempt.
  • The diff is reviewable. startSize: 0.4 -> 0.9 is something a human can approve in two seconds. A rewritten emitter class is not.

The split that actually works

Agent does the mechanical half: scaffold a variant, adjust timings across twelve effects, validate the project, export the bundle. Human does the judgment half: is this the feel we want. That split works because it matches what each side is genuinely good at, rather than hoping the agent develops taste.

What does not work is asking for taste and then being disappointed. “Punchier” needs to become “shorter lifetime, higher initial velocity, faster falloff” before it is a task — and deciding that is the human's job, not a prompting failure.

The unglamorous prerequisite

None of this works if your effects live in a binary blob or behind a GUI. Delegability is decided by your storage format, well before anyone writes a prompt. That is the least exciting sentence here and the one that determines the outcome.
