Notes on web game VFX
Particle effects, frame budgets, and authoring workflow for HTML5 games.

Why these notes exist

Visual effects are the part of a web game that everyone agrees matters and nobody owns. These are notes from working on that gap.

I keep running into the same three arguments: that a stutter is a rendering cost when it is almost always an allocation, that effect authoring is a craft problem when it is usually a queue problem, and that the file format is an implementation detail when it decides whether any of this can be reviewed.

These pages are the short versions. Where somebody else has written the idea up properly, I link out instead of restating it.
